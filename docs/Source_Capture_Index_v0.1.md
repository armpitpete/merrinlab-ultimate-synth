# MerrinLab Ultimate Synth — Source Capture Index v0.1

## Purpose

This document records the contents of the uploaded source archive:

```text
Single Board Analogue Synths.zip
```

The archive contains local captures of the MFOS Sound Lab Ultimate and Sound Lab Ultimate Expander source pages.

Do not commit the full copied MFOS archive or original images into this repo unless copyright/licensing has been checked. Use this index to identify which captured files should be inspected when correcting the project design documents.
