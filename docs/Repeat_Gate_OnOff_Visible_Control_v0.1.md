# Repeat Gate On/Off Visible Control v0.1

Issue #56 adds a visible faceplate on/off control for Repeat Gate.

Existing audio state key:

```text
repeatGate
```

Existing values:

```text
off
on
```

Visible placement:

```text
Rpt. Gate Rate / Gate LED
```

Scope:

- visible Repeat Gate on/off only
- no audio engine change
- no timing change
- no BPM conversion change
- no Gate jack activation
- no MIDI clock
- no sync
- no presets
- no save/load

Good enough:

```text
Visible Repeat Gate on/off controls the existing repeatGate state only.
```
